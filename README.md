# Digital Dashboard PCB Design in KiCad 

-Designed a 2-layer microcontroller-based dashboard system using a custom
microcontroller and a LCD interface.

-Integrated analog and digital inputs for automotive monitoring, including RPM, Speed,
Fuel Level, and Oil/Coolant Temperature sensors.

-Created custom schematic symbols and IPC-compliant footprints for components such
as SO-28, SOT-223, and TO-220 packages.

-Managed power distribution using LM7805 and LM317 voltage regulators, adhering to
strict track width requirements (0.6mm for power, 0.25mm for signals).

-Executed the full PCB design flow from schematic capture to Gerber generation for a
mixed-signal dashboard using KiCad.

Finalized manufacturing outputs including Drill files, Assembly drawings, and 3D model
integration.
